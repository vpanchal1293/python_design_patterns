A class should not be forced to depend on methods it does not use.

| Concept       | Description                                             |
| ------------- | ------------------------------------------------------- |
| **Principle** | Interface Segregation Principle                         |
| **Problem**   | Classes are forced to implement methods they don’t use  |
| **Solution**  | Split large interfaces into smaller, role-specific ones |
| **Benefit**   | Cleaner, more modular, and more reusable code           |
