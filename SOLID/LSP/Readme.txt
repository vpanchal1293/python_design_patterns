Objects of a superclass should be replaceable with objects of its subclasses without affecting the correctness of the program.
| Concept       | Description                                                                                                |
| ------------- | ---------------------------------------------------------------------------------------------------------- |
| **Principle** | **Liskov Substitution Principle (LSP)**                                                                    |
| **Problem**   | Subclasses that don’t behave like their parent class cause unexpected behavior when used polymorphically.  |
| **Solution**  | Subclasses should be **replaceable for their base class** without altering the correctness of the program. |
| **Benefit**   | Ensures consistency, reliability, and safe polymorphism in object-oriented designs.                        |
